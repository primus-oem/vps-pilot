# VPS Pilot

VPS Pilot — локальный Go MCP-сервер и CLI для безопасной эксплуатации VPS, плюс TypeScript-расширение VS Code. Цель первой полноценной версии — вести несколько хостов и репозиториев, описывать многосервисные приложения, планировать и выполнять подтвержденные Docker Compose-развертывания, управлять файловыми секретами, проверять здоровье и восстанавливать совместимые релизы.

## Статус

Реализован начальный каркас core и VS Code extension. Go CLI запускает MCP stdio server и команду `version`; MCP tool `get_policy_capabilities` сообщает, что операции пока выключены. SQLite state и первая migration создаются локально с ограниченными правами. Extension регистрирует настроенный локальный binary как MCP server.

Пока не реализованы: SSH/host inventory, Compose import и deployment, secret intake, approvals и production operations. Текущий код не является готовым инструментом эксплуатации и не должен подключаться к production.

Локальные проверки:

```sh
cd core && go test -p=1 ./... && go vet ./... && go build ./cmd/vps-pilot
cd ../extension && npm ci && npm audit && npm test && npm run compile
```

Команды deployment и обслуживания в runbook — целевой процесс; использовать только функции, доступные в установленной версии.

## Безопасность

- MCP не получает произвольную оболочку, произвольное чтение файлов или значения секретов.
- Изменения проходят через типизированный план; production требует локального одноразового подтверждения точного digest плана.
- SSH использует ключи и проверенную идентичность хоста. Пароли не являются конфигурацией продукта.
- Compose secrets — файловая доставка секретов, не зашифрованное хранилище. Доступ к rootful Docker socket или группе `docker` обычно эквивалентен root.
- Ошибка или прерывание развертывания должны оставлять журналируемое состояние для сверки, а не создавать обещание атомарного отката.

До независимого аудита и прохождения acceptance-критериев продукт нельзя представлять как прошедший аудит или готовый для production.
